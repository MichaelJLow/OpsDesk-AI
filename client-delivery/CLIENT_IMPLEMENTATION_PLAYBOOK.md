# Client Implementation Playbook

Methodology only — not a claim of completed client delivery.

## Stages

1. **Initial discovery** — outcome, workflow boundary, stakeholders, channels, systems, risks.  
2. **Current-state workflow audit** — steps, owners, systems, decisions, waits, failures.  
3. **Baseline measurement** — volume, handle time, rework, escalations (never invent).  
4. **Systems & integration inventory** — APIs, ownership, source of truth.  
5. **Risk and control design** — what is deterministic / AI-assisted / human-approved / prohibited.  
6. **Future-state design** — maps, architecture, acceptance criteria, non-goals.  
7. **Sandbox / synthetic pilot** — test accounts, scenarios, evaluation, issue log.  
8. **Shadow mode** — recommendations vs staff decisions; no external side effects.  
9. **Controlled pilot** — one workflow, one team, restricted permissions, rollback.  
10. **Production rollout** — least privilege, monitoring, change control.  
11. **Handover & improvement** — runbooks, versions, ownership, review cadence.

## Engagement shapes (no prices)

- Workflow Audit  
- Controlled Pilot  
- Production Implementation  
- Ongoing Improvement  

## Rules

- Separate synthetic demo claims from client work.  
- Do not automate all departments at once.  
- Document approval authority before enabling writes.
